---

## 🌟 Highlights & Features

- **Editorial Folder-Tab & Dossier Aesthetic**: Inspired by creative designer binders, retro macOS window frames, metric badges (`+50% Reach`), and tactile card tabs.
- **Light & Dark Theme Modes**: Seamless switching between Warm Paper/Folder Blue mode and Dark Matrix/Graphite terminal mode with `localStorage` memory.
- **Interactive Project Filtering**: Instant filtering across *All*, *C++ Systems*, *Web & UI*, *Cloud & Network*, and *AI*.
- **Interactive Skills Navigator**: Quick categorized tabs for *Programming*, *Web Dev*, *Cloud & Data*, *Tools & Design*, and *Currently Exploring*.
- **Quick Contact Utilities**: 1-click **Copy Email** (`kanu081106@gmail.com`) with toast notification, interactive message preparation, direct links to GitHub & LinkedIn.
- **Ultra-Lightweight & Zero-Build**: Built purely with semantic HTML5, modern CSS3 (custom properties, flexbox, CSS grid, container queries), and vanilla JavaScript. No node build steps required to run or deploy!
- **Fully Responsive & Accessible**: Optimized for mobile screens, tablets, and high-DPI desktop displays.

## 🚀 Running Locally

You can preview the website immediately with any simple web server:

### Option 1: Python
```bash
python -m http.server 3000
```
Then visit [`http://localhost:3000`](http://localhost:3000) in your web browser.

### Option 2: Node.js (via `npx serve`)
```bash
npx serve .
```

### Option 3: Direct Double Click
Simply double-click `index.html` in your file explorer to open it in Chrome, Edge, or Firefox.

## 🌐 Deploying to GitHub Pages (Free Hosting)

1. Initialize a git repository in this folder (if not already done):
   ```bash
   git init
   git add .
   git commit -m "feat: complete portfolio website"
   ```
2. Create a new repository on GitHub named `portfolio` or `<your-username>.github.io` (e.g. `kanu-sheoran.github.io`).
3. Push your code:
   ```bash
   git remote add origin https://github.com/kanu-sheoran/portfolio.git
   git branch -M main
   git push -u origin main
   ```
4. On GitHub, navigate to **Settings** → **Pages** → under **Branch**, select `main` and `/ (root)` → Click **Save**.
5. Your portfolio will be live at `https://kanu-sheoran.github.io/portfolio/` in seconds!
